# Native static joined-vacuum retained acceptance

This test exercises the actual native source-free RZ vacuum endpoint with a positive-density core, true empty exterior, periodic z and a radial PEC wall. It changes acceptance ownership only. It does not admit circuit, prescribed drive, external fields, stopping or physical events.

The input is copied from the frozen parent R71 accepted MM0 pilot. The original identically-zero external parser remains enabled in both arms because this flag also selects the required native A wall pin. A separate add_external_fields=0 attempt fails the existing recovery capability guard and is preserved. Retained admission checks the actual scale equals zero, no parser symbols and no device/Python segments; nonzero, time-dependent and segment cases reject. MM0 uses deposited density; MM1 uses the already-qualified interval-current and companion tangent plus density projection. The existing numerical and thermal gates are unchanged.

Each positive runs a rejected candidate, then the same accepted steps, a clean retained control and a nonretained control. Rejection occurs before endpoint, after endpoint, or from an invalid candidate density. The complete registered accepted field storage, private field histories, initialized/level flags, particle maps/all attributes, RNG/NextID, time, and actual reduced-diagnostic state are compared byte for byte on CPU. Exactly nine pointer-identified native tangent bands are derived scratch; their caches are invalidated rather than restored. Rejected-only relocation crosses the rank boundary after endpoint verification and proves full-map restoration, not a physical orbit-crossing capability.

The native midpoint Poynting sample remains at its original time level. Its data and private sample flag are in the raw snapshots; its checkpoint file is compared before/after veto and retry/clean. Direct Try preflight negatives cover density, mask, time and baseline layout without state mutation. Scope negatives retain guards for density projection without MM, Joule and external drive.

Configure this standalone directory with NATIVE_RETAINED_VACUUM_EXECUTABLE pointing to the coherently linked executable, then run CTest. CUDA builds may compile/run the executable under a separately declared arithmetic comparison; the registered Python tests deliberately retain the CPU exact recomputation contract.
