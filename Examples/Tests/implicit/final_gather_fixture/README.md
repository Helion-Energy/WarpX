# Exact final inner Boris gather capture

`implicit_evolve.thermal.audit_ion_electric_work = 1` optionally records the final inner particle iteration's actual Cartesian gather point, in metres, including in RZ. Default is zero. Charged physical species receive `implicit_final_gather_x`, `_y`, `_z` runtime real attributes with `comm=0`, exactly like saved implicit state. Added memory is `3*sizeof(ParticleReal)` per charged particle (24 bytes in DP; zero when disabled). These scratch values are neither communicated nor checkpointed.

The native MC/Direct gather writes its already-computed post-crop point through an optional output pointer. No cropping calculation is duplicated. The pusher resets scratch to NaN for each evaluation, then records that point immediately before each Boris push. The last inner iterate remains recorded even though its following position update changes the stored midpoint. Existing physical updates, iteration termination, deposition and tolerances are unchanged.

Capture is limited to new Eulerian energy modes, RZ or Cartesian 3D, shape3 momentum-conserving gather and Boris. Registration rejects suborbits, subcycled species and configured in-push radial wall reflections. Native species validation rejects no-push, no-gather, field ionization/variable-charge attributes, classical radiation and enabled QED paths. The same validation runs on push and in the recorded acceptance bridge, so changing native skip flags cannot silently validate stale scratch. The pusher also rejects a nonpositive iteration count or inconsistent late suborbit/reflection options. Direct suborbit advancement rejects capture too. Existing zero-particle and no-suborbit early returns remain unchanged. Later collisions, stopping, boundary reflection and OU updates must occur **after** the receipt; the capture does not include their work.

`MeasureNativeImplicitIonElectricWork` requires all three recorded arrays and reports `RecordedFinalGather`. `MeasureNativeReconstructedIonElectricWork` retains the older approximation under an explicit name and always reports `FinalMidpointReconstruction`. The caller must provide immutable actual final-iterate auxiliary component fields with the native centering and filled guards, including any extra electric fields for a total-work identity. The attributes alone do not attest to a field generation or nonlinear iteration. Consume them before endpoint extrapolation, boundary actions, redistribution, collisions or stochastic kicks. Parent integration owns actual eta-component capture and that acceptance ordering.

The registered native test calls the real `PhysicalParticleContainer::ImplicitPushXP`, pushes a nonzero subrange, checks untouched neighbors, replays Boris from the captured point, and evaluates the native work bridge. A one-iteration control makes the updated midpoint observably different; a converged iteration control checks the final overwrite. PEC cropping is exercised in RZ Cartesian coordinates and in 3D. On/off physical particle output is compared bitwise and the full native checkpoint header must exclude the scratch names. Expected startup and late-mutation guard failures are checked by their actual rejection messages. MPI runs cover seams and an empty rank.

Through a normal configured WarpX RZ/3D build, build `test_final_gather_capture_rz` / `_3d` and run `ctest -R final_gather`. The Python driver also accepts `--ranks 2 --cells 16 --grid 8` for a seam case and `--ranks 2 --grid 64` for an empty rank. `MPIEXEC` selects the MPI launcher and `MPIEXEC_PREFLAGS` supplies any vendor-specific options. `--baseline` adds a bitwise comparison against a fixture linked to the original pusher. Every run uses fresh output directories, retaining failure logs.

No total force/work application closure is claimed by these capture fixtures. QED execution is unsupported and explicitly rejected; it is not an enabled physics validation case. No GPU execution is required for the CPU native fixture.
