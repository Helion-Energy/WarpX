This fixture preserves a physical fixed-density stopping event, then advances the native pressure/Hall PEC branch for two steps. It checks the actual kernel capture, raw registry/particle/RNG purity, independent grow1 Je/D/W phase, raw PEC constitutive row, exact wall support and zero constrained-row electric work. Exact event rollback/recomputation is a CPU qualification only. CUDA compiles the same native fixture; no GPU byte-recomputation claim is made.

Register this directory only when `TARGET lib_rz` exists. Its production prerequisites are the accepted stopping context, repaired gather geometry, exact stopping transpose, spatial/RZ event helper and PEC plasma constitutive patch. A standalone importer accepts `-DNATIVE_PEC_PLASMA_EXECUTABLE=/absolute/path/native_pec` and optional `-DMPIEXEC_EXECUTABLE=/absolute/path/mpiexec`. Python requires NumPy for independent represented-input phase arithmetic.

The input enables no Evolve stopping/collision source. The event is a fixture-owned accepted boundary transaction and does not qualify a general event driver. The branch is opt-in; no viscosity/resistivity/drive/vacuum/OU or MM-Jv admission. The event and subsequent evolution retain finite MC/current and total-energy defects. Checkpoint, poisoned-storage, full residual-direction, physical rollback/retry and energy inventory receipts accompany the handoff independently; they do not imply total conservation or temporal order.
