# Retained native endpoint acceptance

This fixture checks the opt-in `implicit_evolve.native_retained_acceptance=1` positive-density RZ prerequisite. It uses native initialization and the same `HybridPICInitializeRhoJandB` prelude as Evolve, then directly calls OneStep. The driver publishes time/step only on success. No stopping, collision, circuit, vacuum or physical boundary event is enabled.

All registered FAB bytes, all particle maps/attributes/IDs, host/device RNG, NextID, costs, solver E/Eold/Eprev and step flags, time and step must restore exactly after a declined endpoint candidate. Derived mass matrices and density caches must be invalidated. CPU retry accepted state must equal a fresh clean run byte for byte, and accepted thermal receipts occur once per successful step. The two custom fixture attributes are communicated during native Redistribute.

The MPI relocation case deliberately moves 512 identities between boxes/ranks in the rejected-only AfterEndpoint callback. It proves restoration of a changed particle map. It does not qualify accepted physical support crossings: the native correlated increment still rejects CommonPointSupport crossings. The MPI empty-rank case lets only rank 1 decline; collective rejection and restoration are required. First/warm steps, periodic/PMC and invalid companion cases retain every original native threshold. Preflight also checks unsupported external state and invalid density without invoking the operator or changing any bytes.

The TryConstrain wrapper returns the native coefficient/Schur/FGMRES/physical/companion verification failures that expose statuses. Lower-level fatal MLMG/backend errors and programmer/layout/capability assertions remain terminal; this is not universal exception recovery. The callback cannot mutate clock, boundary tallies or external state, and cannot retain particle views across rollback.

Run standalone with `cmake -S . -B build -DNATIVE_RETAINED_ACCEPTANCE_EXECUTABLE=/absolute/path/native_retained -DMPIEXEC_EXECUTABLE=/absolute/path/mpiexec`, then `ctest --test-dir build --output-on-failure -j2`. A parent with lib_rz can add this subdirectory conditionally. CUDA compiles the same fixture, but runtime CTest registration is withheld: exact in-process rollback and bounded native arithmetic must be assessed separately from nondeterministic GPU atomic recomputation. No physical event or total-energy conservation claim follows from these tests.
